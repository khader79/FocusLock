# FocusLock 🔒

> قفل ذاتي ضد التشتت — اربط نفسك بتحدي كتابة نص قبل أن تُستخدم أي شيء.

**FocusLock** نظام لحجب إغراءات التشتت وإجبارك على الانكباب، بأقفال حقيقية:

- بمجرد أن تبدأ "الجلسة المقفولة" لا تستطيع الإغلاق أو التبديل أو إلغاء التثبيت إلا بعد **إنهاء التحدي** أو **انتهاء المهلة**.
- إغلاق النافذة = استمرار التشغيل، وقتل العملية = مراقب يعيد تشغيلها، والحذف على أندرويد = جهاز مقفل كـ *Device Owner*.
- إن كنت بحاجة حقيقية للهرب فهناك **خطة طوارئ** مدروسة وقفل زمني يعمل بالساعة، لا بالشرف.

## وصف المشروع

FocusLock يمنحك "قفلاً مادياً" على إرادتك الضعيفة اللحظية:

1. تختار **المستوى** (كمية النص والمهل) وتضغط بدء.
2. يُعرض عليك **تحدي كتابة**: نص من كلمات BIP39 طويل، مع مؤقت عدّ تنازلي.
3. حتى تُكمل النص بالكامل (أو تنتهي المهلة) يبقى كل شيء **مقفولاً على النظام كله**:
   - على الحاسوب: النافذة ملء الشاشة وكشك (kiosk)، ومواقع الإغراء تُحجب عبر ملف `hosts`، وأي محاولة خروج تُمنع.
   - على الهاتف: التطبيق يمنع العودة/الإغلاق، ويربط نفسك كـ *Device Owner* بحيث لا يمكنك إلغاء تثبيته بسهولة، ويحجب مواقع الإغراء عبر VPN محلي.
4. السر الذي قفلته يبقى مشفّراً (**Shamir 3-of-5 + AES-256-GCM**) ولا يُفك إلا بعد انتهاء المهلة عبر الخادم.

الهدف متجذّر في فصلٍ نفسي بسيط: **تكلفة الخروج في اللحظة أكبر من تكلفة إكمال النص**.

## هيكل المستودع

```
focuslock/
├─ packages/core/        # منطق مشترك (TypeScript): التحدي، القفل الزمني، الإشعارات
├─ apps/desktop/         # تطبيق الحاسوب (Electron + React)
├─ apps/mobile/          # تطبيق الهاتف (Flutter / Android)
├─ server/               # خادم القفل الزمني (Express + TypeScript)
└─ docs/screenshots/     # لقطات الشاشة
```

| الجزء | التقنية | الدور |
|---|---|---|
| `packages/core` | TypeScript | التحدي، قفل زمني، إشعارات تيليجرام |
| `apps/desktop` | Electron + React | الكشك الحاجب للمواقع + المراقب + التحدي |
| `apps/mobile` | Flutter + Kotlin | التحدي على الهاتف + Device Owner + VPN حاجب |
| `server` | Express + TS | تخزين الأقفال + الإفصاح بعد الموعد (`/lock`) |

## الميزات

### مشتركة
- **تحدي كتابة** قابل للتدرج (مستويات 1–5) بكلمات BIP39 عشوائية وموقّت.
- **قفل زمني (Timelock)**: يشفّر السر بـ AES-256-GCM ويقسّم المفتاح بـ **Shamir Secret Sharing 3-of-5** على GF(256) — أي 3 حصص تعيد الأصل، وأي حصّتين لا تفعلان شيئاً.
- **إشعارات تيليجرام**: عند طلب فتح القفل، عند انتهاء المهلة، وعند موافقة/رفض الشخص الموثوق (`sendTelegram`).

### سطح المكتب (`apps/desktop`)
- نافذة **كشك** بملء الشاشة: بلا إطار، بلا زر إغلاق، بلا شريط مهام، ودائمًا في الأعلى (مستوى شاشة القفل).
- **حصانة** (`hardenApp`): إزالة القوائم، منع فتح نوافذ/تصفح جديد، وحجب F11، Ctrl+W، Ctrl+R، Ctrl+Shift+I.
- **حاجب المواقع** عبر ملف `hosts` (قائمة `blocklist.txt` مع تحديث تلقائي) — يتطلب صلاحيات الإدارة (UAC / sudo).
- **مراقب** (`watchdog`): إعادة تشغيل تلقائية + منع تشغيل أكثر من نسخة.
- IPC نظيف عبر `window.api` (`challenge:new`، `challenge:check`، `challenge:giveup`).

### الهاتف (`apps/mobile`)
- شاشة تحدٍّ ترفض الخروج (`PopScope canPop: false`) مع تلوين التقدم وعداد.
- **Device Owner**: قفل الشاشة فوراً (`lockNow`) ومنع إلغاء التثبيت (`setUninstallBlocked`).
- **VPN محلي** (`FocusVpnService`) يحجب مواقع الإغراء على مستوى DNS دون إنترنت.

### الخادم (`server`)
- `POST /lock` → `{ id, releaseAt }` مع التحقق من المدخلات وحدّ معدّل الطلبات.
- `GET /lock/:id/status` → `{ ready, releaseAt }`.
- `GET /lock/:id/reveal` → `403` ما دام القفل قائماً، وإلا يُعيد السر المشفّر.

## التثبيت والتشغيل

### وضع التطوير (dev)

```bash
# 1) تثبيت اعتماديات المساحة (workspace)
pnpm install

# 2) بناء الحزمة الأساسية أولاً (مطلوب للـ desktop/server)
pnpm -F @focuslock/core build

# 3) تشغيل كل شيء (core watch + desktop dev + server dev)
pnpm dev
```

الهاتف (فى مجلد منفصل):

```bash
cd apps/mobile
flutter pub get
flutter run
```

الخادم وحده:

```bash
pnpm -F @focuslock/server dev        # tsx watch src/index.ts
# السيرفر يتحدث على :3000 (غيّره بـ PORT)
```

### الإنتاج (production)

| الهدف | أمر البناء | الناتج |
|---|---|---|
| الحزمة الأساسية | `pnpm -F @focuslock/core build` | `packages/core/dist` |
| سطح المكتب | `pnpm -F @focuslock/desktop build` | `apps/desktop/out` |
| الهاتف (APK) | `cd apps/mobile && flutter build apk --debug` (أو `--release`) | `build/app/outputs/flutter-apk/app-debug.apk` |
| الخادم | `pnpm -F @focuslock/server build` ثم `node server/dist/index.js` | `server/dist` |

> ملاحظة: **GitHub Actions** (`.github/workflows/build.yml`) تبني ما سبق تلقائياً — سطح المكتب على
> Windows/macOS/Linux ورفع الـ APK — وعلى وسم `v*` ينشئ إصداراً (release) يضم كل الملفات.

ملاحظة الـ desktop: `electron-vite build` يجمّع حزم JS حسب المنصة؛ أما **المثبِّتات** (NSIS/dmg/AppImage)
فتحتاج إعداد `electron-builder` — لاحظ الـ TODO في الـ workflow.

## كيف تحمي نفسك من إلغاء التطبيق

### على أندرويد (الأقوى عملياً)

1. **صيّر التطبيق Device Owner** بعد التثبيت (يتطلب كابل USB ووضع مطوّر):

   ```bash
   adb shell dpm set-device-owner com.example.focuslock/.AdminReceiver
   ```

   - التطبيق يعلن `android:testOnly="true"` في `AndroidManifest.xml` حتى ينجح الأمر حتى لو وُجدت حسابات على الجهاز.
   - ⚠️ للإصدار النهائي يُنصح بإزالة `testOnly` تجهيزاً للإصدار التجاري (Play Store يرفضها).

2. **فعّل الحماية من الإلغاء** من كودك:

   ```dart
   // apps/mobile/lib/admin.dart
   await Admin.isDeviceOwner();          // > true بعد الخطوة 1
   await Admin.setUninstallBlocked(true); // يمنع إلغاء التثبيت من النظام
   await Admin.lockNow();                 // قفل فوري للشاشة
   ```

3. **الخلفية**: `BootReceiver` يعيد تشغيل `FocusVpnService` عند كل بوت، فيبقى حاجب المواقع نشطاً حتى بعد إعادة التشغيل.

### على سطح المكتب

- تشغيل التطبيق **بصلاحيات الإدارة** (أو `sudo`) يجعله قادراً على الكتابة في ملف `hosts` — وتعديل الـ hosts بيد مستخدم عادي مرفوض من النظام.
- `hardenApp` يجعل الخروج بالطرق التقليدية متعذراً، و`watchdog` يعيد التشغيل إن انتهت العملية قسراً.
- نسخة المراقب الوحيدة (pid file) تمنع فتح نسختين تهرب إحداهما بالقفل.

> الحقيقة الأمنية: من يملك صلاحية `sudo`/ADMIN على نظامه سيجد دائماً طريقة (إن كان يريدها فعلًا).
> الحماية هنا تجعل الإلغاء **مكلفاً ومكتشفاً** (إشعارات/تدقيق)، لا مستحيلاً، وتحميك من إلغاء **اللحظة الضعيفة**.

## خطة الطوارئ

إن احتجت فعلاً للخروج (سباق، صلاة، أمر طارئ)، إليك المخارج بالترتيب:

### 1) المخارج الشرعية
- **أكمل التحدي** — هذا هو المخرج الأول: اكتب النص وانتهِ. إن فاتت المهلة يتم التصفير تلقائياً (`challenge:giveup`).
- **استسلام مقصود**: زر «استسلام» داخل التحدي يصفّر الجلسة (خيار متاح بوعي).

### 2) على أندرويد
- بعد انتهاء المهلة يُريح الشاشة نفسها ويفتح سرّك.
- **خلع الهاتف من الالتزام**: أوقف الـ VPN من الإعدادات، ثم أزل التطبيق من شاشة المديرين:
  - من الجهاز: `الإعدادات ← الأمان ← تطبيقات مدير الأجهزة ← ألغِ تفعيل FocusLock`.
- **عبر الحاسوب** (يتطلب تصحيح أخطاء USB):

  ```bash
  adb shell dpm remove-active-admin com.example.focuslock/.AdminReceiver
  adb uninstall com.example.focuslock
  ```

- آخر ملاذ: **إعادة ضبط المصنع** (مسح كل شيء — الكل يفقد السر).

### 3) على سطح المكتب
- **القتل القسري** (لا يُعيد المراقب التشغيل، لأنه ينجو فقط من القتل اللطيف):

  ```bash
  # Windows
  taskkill /F /IM focuslock.exe
  # macOS / Linux
  pkill -9 -f focuslock
  ```

- **إزالة الحجب**: احذف الكتلة المُعلَّمة من ملف `hosts` (المحددة بين
  `# === FOCUSLOCK START ===` و`# === FOCUSLOCK END ===`) — تتطلب صلاحية إدارة.
- يمكنك أيضاً مسح `watchdog.pid` وحذف `blocklist.txt` من مجلد بيانات التطبيق قبل الخروج.

### 4) القفل الزمني (Timelock) — خطة الأمان الحقيقية
- سرّك **لا يمكن فكّه مبكراً**: مفتاح الـ AES موزّع على أشخاص موثوقين (Shamir 3-of-5).
- بعد `releaseAt` يُصدر الخادم السر عبر `GET /lock/:id/reveal`، وتجمع 3 حصص فتستعيد المفتاح.
- **التواصل**: الشخص الموثوق يتبلّغ بالموافقة/الرفض فوراً عبر `notify` (تيليجرام) — ضع عين الرقابة في حساب شخص مجرّب.
- احتفظ دائماً بـ **3 حصص على الأقل لدى 3 أشخاص مختلفين** حتى لا تفقد السر إذا ضاع هاتف أو جهاز.

### قواعد ذهبية
1. لا تخزن كل الحصص في مكان واحد.
2. احتفظ بنسخة احتياطية من `blocklist.txt` خارج الجهاز.
3. جرّب خطة الطوارئ على جهاز تجريبي قبل أن تحتاجها فعلاً.

## البنية التقنية

| المكوّن | الملفات الرئيسية | الوصف |
|---|---|---|
| التحدّي (core) | `packages/core/src/challenge.ts` | توليد النص من 2048 كلمة BIP39 + تفريقات وأنماط تحقق |
| القفل الزمني | `packages/core/src/timelock.ts` | Shamir على GF(256) + تشفير AES-256-GCM |
| الإشعارات | `packages/core/src/notify.ts` | `sendTelegram` + أحداث القفل والموثوق |
| الحصانة (desktop) | `apps/desktop/src/main/admin.ts` | `hardenApp`: القوائم، التنقل، الاختصارات |
| حاجب المواقع | `apps/desktop/src/main/blocker.ts` | ملف `hosts` + `blocklist.txt` + تحديث دوري |
| المراقب | `apps/desktop/src/main/watchdog.ts` | إعادة تشغيل + نسخة واحدة |
| IPC | `apps/desktop/src/main/index.ts` | `challenge:new` / `challenge:check` / `challenge:giveup` |
| Device Owner | `apps/mobile/lib/admin.dart` | `isDeviceOwner` / `setUninstallBlocked` / `lockNow` |
| VPN حاجب | `apps/mobile/.../FocusVpnService.kt` | `DnsPacket` + `Blocklist` على مؤمن VPN محلي |
| مؤثر البوت | `apps/mobile/.../BootReceiver.kt` | إعادة تشغيل الـ VPN بعد الإقلاع |
| الخادم | `server/src/index.ts` | الأقفال في `Map` (مع TODO للـ Redis) + رصد/تحقق |
